# DEV-004: test_complex_hollow does not fracture; the fixture is unprocessed

**Date:** 2026-08-08
**Category:** spec_deviations
**Related Docs:** docs/14_test_environment.md#D14-S7.1, docs/09_blender_destruction_tool.md#D09-S5.2

**Status:** active

## Summary
Four of the five D14-S7.1 fixtures process to exit 0. `test_complex_hollow` does not: the shard mass sum comes out at 13571 kg against a true part mass of 2127 kg — 6.4x — so the tool correctly refuses it with `MASS_IMPLAUSIBLE` (72). The fixture is excluded from `:blender-tool:processFixtures` until the cause is fixed.

## Details

**Deviates from:** (D14-R20), which lists five checked-in fixtures each with a golden manifest.

**Cause:** the bisection fracture of DEV-002 clips a mesh with an *internal cavity*. Each cell's cut boundary is two nested loops in one plane — the outer wall and the cavity wall — and filling that boundary as a single face swallows the cavity, so each cell measures as solid. Switching from `holes_fill` to `triangle_fill` with an explicit plane normal improved other cases but did not fix this one; the nested-loop fill still bridges the two loops.

**What is *not* wrong:** the volume formula. `test_complex_hollow`'s source mesh measures 0.2710 m3 (2127 kg at steel density), which is the wall volume, not the 1 m3 bounding box. The divergence-theorem computation handles the inward-wound cavity correctly. The defect is confined to what the *clipping* stage produces.

## Rationale / Context
Without this entry the next session sees four fixtures where the spec names five, and either assumes the fifth was forgotten or re-derives the cavity problem from scratch. The failure is also easy to misread as a volume bug, which it is not.

## Impact
`fixtures/meshes/test_complex_hollow.glb` (generated but unprocessed), `blender-tool/build.gradle.kts` `fixtureSpecs`, and `.agent-memory/progress/PROG-002.md`.

**Blueprint Disposition: IMPL_SHOULD_CHANGE.** The fixture is a legitimate requirement — D14-S7.1 says its purpose is exactly to test that mass is not computed from a bounding box — and the tool must eventually handle it. A planar-cut fill that treats an inner loop as a hole, or clipping the outer and inner shells separately and recombining, are the two candidate fixes.
