# DEV-017: a replay steps the whole physics world, not just the local vehicle's body

**Date:** 2026-08-13
**Category:** spec_deviations
**Related Docs:** docs/10_networking_multiplayer.md#D10-S5.5, docs/06_physics_simulation.md#D06-S5.4

**Status:** active

## Summary
D10-S5.5 step 3 replays unacknowledged inputs with `world.stepPhysicsOnly(TICK_DT)` and the comment
"only the local vehicle's body needs re-simulating". `ReconciliationSystem` steps the entire
`btDiscreteDynamicsWorld` per replayed input and then restores every remote entity from the newest
snapshot.


## Details
Bullet has no API to advance one body inside a world. DEC-004 puts every vehicle in one dynamics
world with one compound shape each, and DEC-002's ray-cast vehicle is driven by the world's own
step — so "step this body" does not exist to be called.

What the implementation does instead is bounded and self-correcting. A replay is `n` steps where
`n` is the number of unacknowledged inputs, typically five to ten at a playable latency and capped
by the 128-command prediction buffer. Remote bodies are advanced by those steps and then put back
by `NetworkClient.reapplyLatestFrame`, which writes them to exactly the state the newest snapshot
carries — which is where they were going to be set from anyway (D10-R19, D10-R22).

## Rationale / Context
The residue is real and worth naming: during the replayed steps, remote bodies are in the wrong
place, so a *collision* resolved inside a replay is resolved against stale remote positions. That
cannot corrupt authoritative state — a client authors none (G15) — but it can make a local
prediction worse for one frame after a correction that involved contact, which is the one case
where prediction is already worst.

## Impact

**Blueprint Disposition: DOC_SHOULD_CHANGE.** The requirement deviated from is (D10-R19).
- `ReconciliationSystem.replayPendingInputs` calls `PhysicsWorld.step()`.
- D10-S5.5's pseudocode should be amended to describe a whole-world replay with a restore, once the
  networking phase is finished and the section is being revised anyway.
