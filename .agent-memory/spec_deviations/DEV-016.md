# DEV-016: the crank is twice as long as the recording it was measured from

**Date:** 2026-08-13
**Category:** spec_deviations
**Related Docs:** docs/15_vehicle_preparation_pipeline.md#D15-S8, D15-R38a9

**Status:** active

## Summary
R38a9 requires ignition timing to be measured rather than invented, and it was: a Ford Mustang GT
cranks for about 0.54 s before catching. Reproduced faithfully, the user reported "a complete lack
of a startup sound". The crank is now 1.12 s for an eight — roughly double the measured value — and
the starter is louder and audibly labours on each compression.

## Details

**Requirement deviated from:** D15-R38a9, "ignition timing is measured, not invented, and its parts
scale with the arrangement".

**What the recording says.** The crank is brief to the point of sitting under the ambience, and the
engine is at full voice 40 ms after the first sign of it. R38a9 exists because a *previous* attempt
invented a 0.62 s crank with a 0.3 s ramped catch, which sounds like a diesel in winter.

**Why it is wrong here.** The reference is a phone recording of a car a few feet away in the open,
which the listener is already watching. A car in a game has to announce itself over an arena, from
a listener who is not looking at it, competing with seven others. Half a second — most of it spent
spinning up — is below the threshold at which an event registers as an event at all. The user's
report was accurate: they heard nothing, because functionally there was nothing to hear.

**Scope of the deviation.** Length and level only. Everything about the ignition's *shape* is still
the measured one — the catch is a step and not a ramp, the flare holds about 0.2 s and sits under
3 dB above idle, and both crank duration and crank speed still scale with cylinder count. The
deviation is that several compressions are now individually audible before the catch, which is what
makes a start read as an engine being turned over.

## Rationale / Context
Recorded because the next session measuring against that clip will find the crank twice as long as
the reference and reasonably conclude it drifted. It did not; it was moved, once, deliberately, on
a user report.

## Impact

**Blueprint Disposition: BOTH_VALID.** R38a9 (D15-R38) — its rule is right and its measurement is right;
what neither captures is that a game's audio is heard at a different distance, in a different mix,
by a listener with different attention. That is a general point and R38a9 should probably say it,
but the requirement as written is not wrong, so this is an exception rather than an amendment.

- `EngineRunState`: crank base 0.26 s → 0.62 s, per-cylinder 0.035 → 0.062, labour depth 0.26 →
  0.44, crank pumping 0.55 → 0.28 (a cranking engine is heard through the block, not the pipe).
- `EngineSynth`: starter level 0.20 → 0.42, and a labour term that makes the motor growl as each
  compression drags it down.
