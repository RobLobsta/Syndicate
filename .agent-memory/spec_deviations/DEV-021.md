# DEV-021: two structure models ship with no recorded licence, against D08-R1b

**Date:** 2026-08-18
**Category:** spec_deviations
**Related Docs:** docs/08_asset_pipeline.md#D08-S4.1, docs/16_procedural_arena_generation.md#D16-S7

**Status:** active

## Summary
D08-R1b requires the source, the author and the licence beside every model, and says **a model with
no recorded terms is not processed**. `turret.blend` and `city_alley_kit.blend` arrived with none of
the three. Both were processed, and the five structures cut out of them ship in `assets/`.

## Details

**Deviates from:** the licence half of D08's source-art rule (D08-R1) — recorded there as R1b — "Every directory under `vehicles/`, `weapons/` and `structures/` carries
a `LICENCE.md` naming the source, the author and the licence … A model with no recorded terms is not
processed."

What is knowable is recorded. The alley kit's props are BlenderKit downloads and their asset ids
survive in the packed textures' original Windows paths, so `art-source/structures/*/SOURCE.md` names
each one; BlenderKit hosts under several different licences, so an id says where a model came from
and nothing about what may be done with it. The turret carries no metadata at all — no textures
beyond a generated UV checker, no `asset.extras`, no author string.

Each directory's `LICENCE.md` states the position in full and says what has to happen before
anything ships. The runtime does not care: replacing any of the five `scene.glb` files re-runs the
same tool over the same rules and changes nothing else.

## Rationale / Context
The alternative was to build D16-S7 with no content in it. Structures were the last unbuilt stage of
D16 and the reason the stage had stalled for four sessions; a subsystem with nothing in it cannot be
driven at, shot at or looked at, and this project's last three sessions each found a defect that only
appeared when somebody looked. Refusing the art would have bought a rule and lost the check.


## Impact
**Blueprint Disposition: IMPL_SHOULD_CHANGE.** D08-R1b is right as written. The resolution is to
establish the terms and replace each `LICENCE.md`, not to soften the requirement.

- **Nothing in `assets/structures/` may be distributed** until each model's terms are established.
- The pipeline, the cut, the destruction data and the runtime are all independent of which geometry
  is in `scene.glb`, so replacing a model is a re-run rather than a rewrite.
- Resolving this needs the supplier of `turret.blend` to say where it came from, and each BlenderKit
  asset id to be looked up for its author and licence.
