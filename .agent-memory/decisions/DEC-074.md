# DEC-074: an arena is a theme and a seed, and the seed defaults to the match's

**Date:** 2026-08-14
**Category:** decisions
**Related Docs:** docs/16_procedural_arena_generation.md#D16-S4.2, docs/16_procedural_arena_generation.md#D16-S5.6, docs/08_asset_pipeline.md#D08-S4.7

**Status:** active

## Summary
`TerrainParams.Biome` is replaced by a top-level `ArenaTheme` that owns the relief layer, the surface
palette, the ground albedo and every generator number. An arena declares a theme and a seed and gets
a coherent landscape. A seed of zero means "derive one from the match seed", so a theme generates
maps rather than being one map.

## Details
A biome was a switch inside the generator with the interesting numbers still in the arena file. Eight
of them decide how a place feels — relief amplitude, base frequency, octaves, feature bearing,
wavelength and height, rim width and rise — and they only work in combinations. So "make a scrapyard"
meant knowing which to change together, and two arenas of the same biome could differ more than two
biomes did.

A theme owns them (`ArenaTheme.Shape`) and supplies them as defaults, with anything authored
overriding. `arena_scrapyard_01`'s whole terrain block is now four lines.

Three themes, each with a relief layer and a surface palette:

| Theme | Relief | Ground |
|---|---|---|
| `DESERT_HIGHWAY` | wind-oriented dunes with slip faces at repose | sand, gravel on scoured slopes, rock past repose |
| `SCRAPYARD` | isotropic heaps, thresholded so the yard between them stays flat | old slab, gravel on flanks, hardcore on the piles |
| `PROVING_GROUND` | none | tarmac throughout |

**The seed.** Zero means derived from `world.random().matchSeed()` mixed with the arena id. That is
legal under G4 precisely because it comes from the match seed: every peer shares it and the offline
runner replays it, so authority and client generate identical ground and a match is still
reproducible from its seed alone. Deriving from the clock would not be.

**A derived seed can produce an unplayable map**, and D16-R58's connectivity check found one on the
first run. That check was a hard failure, which is right for an authored arena and impossible for a
generated one — the first player to draw a bad seed would get a crash on the loading screen. So a
match-seeded arena now discards an unplayable field and re-seeds, up to eight attempts. The check
does not soften; only the response to it changes. A declared seed still fails hard, because there is
no other seed to move to.

## Rationale / Context
The failure this prevents is subtle and would have shipped: everything about generated terrain was
verified against one hand-checked seed, so every property anyone measured was a property of that
seed. Sweeping seeds in `ArenaThemeTest` is what turns a theme's name into a promise.

## Impact
- `biome` is gone from the schema; D16-R6 is rewritten and gains R6a, R6b and R6c.
- `arena_scrapyard_01` is a real place: "Scrapyard" now describes what is generated.
- A future best-of-three gets different ground per round for free.
