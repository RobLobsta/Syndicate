# DEC-083: articulation is one block with five motions, extended rather than duplicated

**Date:** 2026-08-16
**Category:** decisions
**Related Docs:** docs/17_weapon_system.md#D17-S4.4, docs/08_asset_pipeline.md#D08-S4.2, docs/15_vehicle_preparation_pipeline.md#D15-S5.6

**Status:** active

## Summary
Weapon movement reuses the `articulation` block D15-S5.6 already defined for doors, extended with a
`motion` discriminator — `HINGE`, `RECOIL`, `SPIN`, `INDEX`, `ELEVATE` — and a `driver` —
`OPEN`, `FIRE`, `CONTINUOUS`, `AIM`. `HINGE` and `OPEN` are the defaults, so every door part both
shipped vehicles already carry keeps working with no file rewritten. It is **cosmetic** (G6), read by
`game-client` and never by `game-core`.

## Details
Two blocks meaning "this part moves" would be a distinction with no difference. Both describe a rigid
transform of one part about a declared axis in its own space, evaluated by the presentation layer;
the door parts would have paid for the split.

**The pose is a pure function of a phase in `[0,1]`.** `PartArticulation.pose(block, phase, out)`
reads no clock, so it is directly testable and two clients handed the same phase draw the same frame.
`ArticulationState` is the half that decides the phase, from `WeaponFiredEvent` on the deferred bus.

**A sub-part inherits its weapon's fire time by slot-path prefix.** The barrel is not the entity that
fires — the mount is — so a shot is recorded against the firing part's slot path and any descendant
recoils with it. One string prefix test, working at any depth.

**The collision hull does not articulate.** A recoiling barrel sweeps no moving collision volume;
that would be cosmetic state feeding the simulation, which G6 forbids and which would make hit
registration depend on frame rate.

## Rationale / Context
The block existed, was authored by `syndicate_prepare` onto four door parts, and **nothing in Java
read it**. Adding a second block would have left the first still unread; extending it made the
door case implemented as a side effect of implementing the weapon case.

## Impact
- `RenderSystem` composes the articulated pose after the render matrix, in the part's local space.
- Every number is derived from a mechanism, not chosen: recoil travel is 4% of barrel length, a drum
  indexes once per shot, a spin coasts to a stop when the gun stops firing. DISC-027's lesson —
  a periodic motion untied to what drives it reads as a fault — applies directly.
- `ELEVATE` authors its axis as **−X**: the world is Y-up right-handed, so a positive rotation about
  +X points the muzzle at the ground.
