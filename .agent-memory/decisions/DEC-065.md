# DEC-065: the pipeline writes import.json, and writes the composition not the residual

**Date:** 2026-08-13
**Category:** decisions
**Related Docs:** docs/15_vehicle_preparation_pipeline.md#D15-S5.5, docs/08_asset_pipeline.md#D08-S4.1

**Status:** active

## Summary
`syndicate-prepare` derives the scale, yaw and translation that put a model in the game's frame and
records them in the model's own `import.json`. DEC-036 stands unchanged — that file is still the
single recorded correction and still what the harness verifies — but an operator no longer has to
author it before the pipeline will run.

## Details
Stage 1 applies whatever `import.json` already says, so what stage 2 derives is a **residual**. What
gets written back is the composition of the two, never the residual on its own.

With the first correction `T·R·S` and the residual `T₂·R₂·S₂`, and both scales uniform, the product
collapses to a single `T'·R'·S'`:

```
S' = s₂·s        R' = yaw₂ + yaw        T' = t₂ + R₂(s₂·t)
```

which is `Correction.then`. Writing the residual instead would discard whatever the old file was
doing, and the next run — which loads through the new file — would arrive at a different vehicle
and derive a third correction. With the composition, a second run's residual is the identity, and
that is asserted rather than assumed (T-D15-27, AC-D15-14).

Two things are deliberately **not** derived. A unit scale is chosen from a closed list of factors
(metric decades, inches, feet) rather than fitted, because a wrong unit is always one of those and a
continuous fit would rescale a genuinely 24 m vehicle to 16 m and report success. And a
misorientation a yaw cannot express — a model on its side, detectable because `y` is not its
shortest extent — is reported and not repaired, under D15-R26's argument: guessing which way up it
should go turns one visible fault into an invisible one.

## Rationale / Context
Without this, "drop in a model and get an asset" is false in its first step: every new vehicle would
need somebody to measure a scale and a yaw by hand before any stage could run, and the measurement
they would be doing is the one the tool does in a millisecond.

The composition rule is the part worth remembering. Writing the residual is the obvious thing to do,
it is correct on the *first* run of a model with no `import.json`, and it silently breaks every
model that already had one — which is both of the vehicles this project ships.

## Impact
- `cleanup.Correction.then`, `prepare._write_import_json`, `--no-write-import` to opt out.
- D15-R25a to R25d record the four rules.
- The tool's determinism (D09-R30) now includes idempotency across runs, not just within one.
