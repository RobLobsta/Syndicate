# DEC-091: MODEL-004's band measures units, not vehicle class

**Date:** 2026-08-17
**Category:** decisions
**Related Docs:** docs/14_test_environment.md#D14-S5.3, docs/00_master_index.md#D00-S4.3

**Status:** active

## Summary
`ModelInspector`'s plausible-extent band goes from 2.5–7.0 m to 2.5–16.0 m, and the two constants are
renamed from `MIN/MAX_VEHICLE_LENGTH_M` to `MIN/MAX_VEHICLE_EXTENT_M`. `MODEL-003` separately gains
percent-decoding of glTF image URIs.

## Details
**MODEL-004.** The Kestrel measures 11.63 m across because its main rotor overhangs the nose, and the
check failed it with the advice to set `scaleToMetres` to 0.396 — which would have produced a
four-metre toy helicopter with a three-metre rotor. The model is correct: it is in metres, at unit
scale, and its airframe is 10.02 m, which is a light utility helicopter's length.

The constant's own docstring already contained the argument for widening it: *"the check is not 'is
this the right car', it is 'is this in metres at all'. The two failures it exists to catch are a
centimetre model (0.05 m long) and an inch-or-unit model (180 long), and both miss this window by two
orders of magnitude."* A 7.0 m ceiling does not test units — it tests *shape*, and it encodes "road
car" into a check that is supposed to be about D00-R11. 16 m still catches both unit errors by two
orders of magnitude and admits any rotorcraft the game is likely to carry.

The rename matters more than it looks: the old name is why the bound was wrong. A constant called
`MAX_VEHICLE_LENGTH_M` invites being set to the longest vehicle, and the thing being measured is the
longest *extent*, which for an aircraft is across the disc rather than along the fuselage.

**MODEL-003.** All three of the Kestrel's textures read as missing. glTF 2.0 §3.6.1.1 makes `uri` a
URI, so a file named `helicopter low_heli_2mt_Albedo.png` is written `helicopter%20low_…` — and
`directory.resolve("…%20…")` finds nothing. The check was reporting a real conformance failure in
itself, not in the model. Decoded with a small hand-rolled loop rather than `URLDecoder`, because a
`+` is a literal plus in a URI path and `URLDecoder` turns it into a space.

## Rationale / Context
The concrete future failure this stops: the next non-car model — a truck, a boat, anything with a
span — fails MODEL-004, and an operator does what the message tells them and scales it. The advice
is confidently worded and wrong, which is worse than no advice; a correctly sized model rescaled by
0.4 then passes every remaining check, and the error surfaces later as a vehicle whose mass, hull and
rotor thrust are all quietly a third of what they should be.

The alternative — making the band vehicle-class aware, read from `import.json` — was rejected as
inventing a schema field to protect a check whose stated purpose does not need one.

## Impact
`test-environment/ModelInspector`: two constants renamed and one widened, `decodeUri` added.
The Kestrel now passes 10/10; both cars are unaffected, sitting well inside the wider band.
