# DEC-020: MASS_DELTA_FRAC aliases MASS_TOLERANCE_FRAC, and COM_OFFSET_M is 0.01 m

**Date:** 2026-08-09
**Category:** decisions
**Related Docs:** docs/08_asset_pipeline.md#D08-S5.4, docs/00_master_index.md#D00-S6.4, docs/06_physics_simulation.md#D06-S4.3

**Status:** active

## Summary
D08 names two tolerance constants — `MASS_DELTA_FRAC` and `COM_OFFSET_M` — that D00-S6.4 never
defines. `AssemblyValidator.MASS_DELTA_FRAC` is an alias of `MASS_TOLERANCE_FRAC` (0.02), and
`COM_OFFSET_M` is fixed at 0.01 m, one collision margin.

## Details
D00-S6.4 is the single authority for cross-cutting constants and its table has no row for either
name. They are referenced by A202, A310, A311, A504 and D08-R10.

**`MASS_DELTA_FRAC = MASS_TOLERANCE_FRAC = 0.02`.** The project defines exactly one mass tolerance,
for G7's shard-mass conservation. Every use of `MASS_DELTA_FRAC` in D08 is also a mass-conservation
check — part mass against manifest mass, shard sum against part mass, an assembly's `expected` mass
against its parts' — so two different fractions would be a distinction with no meaning behind it.
Aliased rather than copied, so there is one number to change.

**`COM_OFFSET_M = 0.01`.** Chosen as exactly `PhysicsWorld.COLLISION_MARGIN_M` (D06-R13): a COM
drift smaller than the collision margin cannot move a contact point, so it cannot change the
simulation, and it is far enough above float noise on a 64-part weighted sum that A311 will not trip
on rounding. Deliberately *not* `MassPropertySystem.COM_SHIFT_EPSILON_M` (1e-6 m), which answers a
different question — "is this shift worth rewriting 64 child transforms for" — and would make A311
fire on content that is correct.

## Rationale / Context
Without this, the next session hitting A310 or A311 either invents a second tolerance (and two
assemblies validate differently on two branches) or amends D00-S6.4 without knowing a value was
already chosen. The names should eventually join D00-S6.4's table; this entry is what an amendment
would be written from.

## Impact
`game-core` `asset` (`AssemblyValidator`). Affects D08-S5.4 A310/A311 and D08-R10. Candidate
amendment to D00-S6.4's reserved-constant table.
