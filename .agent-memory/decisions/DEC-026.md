# DEC-026: steering state lives on the chassis, and every vehicle carries a PlayerInput

**Date:** 2026-08-09
**Category:** decisions
**Related Docs:** docs/04_entity_component_model.md#D04-S4.3.2, docs/04_entity_component_model.md#D04-S4.2, docs/06_physics_simulation.md#D06-S5.5

**Status:** active

## Summary
`VehicleChassisComponent` gains `currentSteerRad` and `VehicleStatsComponent` gains `maxSteerRad`;
D04-S4.3.2 was amended in the same commit for both. `VehicleFactory` also adds a
`PlayerInputComponent` to every vehicle, which D04-R4's `VEHICLE` archetype requires and D05-S5.2's
pseudocode omits.

## Details
**`currentSteerRad`.** D06-S5.5's control loop rate-limits steering toward its target, which needs
the angle it reached last tick. That is cross-tick state, and D04-R3 keeps it out of the system: a
field on `VehicleControlSystem` would be invisible to replication and to a client rewinding across a
reconciliation, so the vehicle would come out of a rewind steering wherever the un-rewound field
happened to point — a divergence that only shows up on a lossy connection.

It is on the chassis rather than on `VehicleStatsComponent` because slot 6 rebuilds that component
from the parts every time it runs (D05-R27), and control state is not derived from parts. Nor on
`WheelControllerComponent`: the angle is one per vehicle, and four copies of it is four chances to
disagree.

**`maxSteerRad`.** D05-S5.6 phase 3 assigns `v.maxSteerRad`; D04-S4.3.2's field list did not have
it. D00-S11 makes D05-S5.6 the authority on stat aggregation, so the component table was amended
rather than the algorithm.

**`PlayerInputComponent` at spawn.** D04-R4's `VEHICLE` archetype lists `PlayerInput | BotController`
and names `VehicleFactory.spawn()` as its creator; D05-S5.2's pseudocode does not add it. D04 owns
the archetype table, so it wins (D00-S5.1). It is added whether or not the vehicle has an owner: a
driverless vehicle with zero input is a parked vehicle, and `VehicleControlSystem`'s family requires
the component, so a vehicle without one silently cannot be driven — by a human or by a bot, which
write the same component.

## Rationale / Context
The two component fields are the kind of addition a later reader assumes was always in D04-S4.3.2;
recording them keeps the amendment traceable to the algorithm that needed them. The
`PlayerInputComponent` line is the one that would cost real time: a vehicle missing it spawns
correctly, has correct mass and stats, and simply never appears in slot 7's family — a bug with no
error message anywhere.

## Impact
`game-core` `component` (`VehicleChassisComponent`, `VehicleStatsComponent`) and `vehicle`
(`VehicleFactory`). Amends `docs/04_entity_component_model.md#D04-S4.3.2` in the same commit.
