# DEC-027: steer lock, steer rate, drag and rolling resistance are named constants

**Date:** 2026-08-09
**Category:** decisions
**Related Docs:** docs/05_vehicle_part_system.md#D05-S5.6, docs/05_vehicle_part_system.md#D05-S4.5, docs/08_asset_pipeline.md#D08-S4.2

**Status:** active

## Summary
Four numbers D05-S5.6 needs and no document authors: `DEFAULT_MAX_STEER_RAD = 0.5236` (30°),
`DEFAULT_STEER_RATE_RAD_PER_SEC = 1.05`, `CHASSIS_DRAG_COEFFICIENT = 12.0` N per (m/s)², and
`CHASSIS_ROLLING_RESISTANCE = 0.015`. All four live on `VehicleStatsSystem` with the reasoning below.

## Details
**Steering.** D05-S4.5 makes `maxSteerRad` and `steerRateRadPerSec` vehicle-scope stats contributed
by wheels, but neither the stat table nor D08-R5's part schema carries a value, and D06-S4.5's
tuning table has no row for either. They are resolved through `baseStats.resolve(stat, default)`, so
a part that authors nothing gets the default and a part that authors something overrides it — the
same shape DEC-022 used for wheel friction and stiffness.

Thirty degrees is a road car's lock. More makes an arcade vehicle spin on the spot at speed, which
reads as broken rather than as agile. The rate is half a second from centre to full lock; a keyboard
produces steering input that jumps between −1, 0 and 1, and a vehicle that followed it exactly would
put its lock on in one 16 ms tick and flip.

**Drag and rolling resistance.** D05-S5.6 phase 4 takes `k_drag` and `k_roll` "from the chassis
part". No part schema field carries either (D08-R5) and no other document names one. 12.0 puts a
20 kN chassis's top speed at roughly 40 m/s, which is `MAX_VEHICLE_SPEED_MPS` — so the drag curve and
D06-S5.5's anti-tunnelling clamp agree, instead of the clamp being what a vehicle actually drives
against. 0.015 is a road tyre's rolling resistance coefficient.

## Rationale / Context
Without this, a session tuning handling finds four magic numbers in the aggregation code and no way
to tell which were chosen and which were typed — the same problem DEC-022 was written for. It also
names the amendment path: if these should be authored, D05-S4.5's stat table and D08-R5's part
schema are what change, and the constants become fallbacks.

## Impact
`game-core` `system` (`VehicleStatsSystem`). Affects D05-S5.6 and, if the gap is closed by
authoring, D05-S4.5 and D08-R5.
