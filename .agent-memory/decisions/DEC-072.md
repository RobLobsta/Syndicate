# DEC-072: menu type is rasterised by FreeType, with the bitmap font as a fallback

**Date:** 2026-08-14
**Category:** decisions
**Related Docs:** docs/02_technical_architecture.md#D02-S4.1, docs/03_runtime_modes.md#D03-S5.1, docs/08_asset_pipeline.md#D08-S4.6

**Status:** active

## Summary
`game-client` gains `gdx-freetype`, and `assets/fonts/` gains Oswald under the SIL Open Font License.
Menu text is rasterised at the pixel size it is drawn at, cached per size. If the native or the font
file is missing, every request returns libGDX's built-in bitmap font and the game still starts.

## Details
The built-in `BitmapFont` is a 15-pixel raster. The shell draws its title at 76 design units and its
headings at 30 to 40, so the cheap version magnifies a 15-pixel glyph by up to five times. The first
capture of the main menu showed exactly that, and blurred type is the single largest reason a menu
reads as a prototype rather than a product.

Alternatives rejected:

- **Scale the built-in font.** What was there. Mush at any heading size.
- **Ship a pre-baked `.fnt` atlas per size.** No new dependency, but the sizes have to be chosen at
  authoring time, and this layout is resolution-scaled — a 4K display asks for sizes nobody baked.
- **scene2d with a skin.** Brings a widget toolkit, a skin file and a layout system to draw a title,
  a list and a stat block, none of which the HUD needed.

Oswald is a condensed grotesque, which suits an industrial vehicular-combat game and is legible at
small sizes in a stat table. It is OFL, so shipping it in `assets/` carries no obligation beyond
keeping the licence beside it, which `assets/fonts/OFL.txt` does.

The fallback catches `LinkageError` as well as `RuntimeException`: a missing FreeType native fails
when the class is first touched, not when the file is read, and a `catch (RuntimeException)` alone
would let it kill the process.

## Rationale / Context
Adding a dependency to satisfy an aesthetic is worth questioning, which is why the alternatives are
written down. The reason it survives the question is that this is the *first screen a player sees*,
and the fallback means the dependency can fail without costing anything but looks.

## Impact
- `libs.versions.toml` gains `gdx-freetype` and its natives, on the pinned `gdx` version.
- The distribution grows by about 3 MB of native and 170 KB of font.
- `MenuFonts.isScalable()` reports which path is live, so a capture can say what it photographed.
