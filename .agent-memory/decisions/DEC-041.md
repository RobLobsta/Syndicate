# DEC-041: the asset pipeline validates independently of the runtime loader

**Date:** 2026-08-10
**Category:** decisions
**Related Docs:** docs/08_asset_pipeline.md#D08-S5.2, docs/08_asset_pipeline.md#D08-S5.4, docs/02_technical_architecture.md#D02-S4.5

**Status:** active

## Summary
`asset-pipeline`'s `AssetIndexBuilder` reads `assets/` with its own Jackson walk rather than calling
`game-core`'s `AssetLoader`. The two share the D08-S5.4 rule codes and nothing else.

## Details

**It is not allowed to share.** D02-S4.5 puts `asset-pipeline` on `shared-models`, Jackson and a
schema validator, and `ModuleRules` enforces it: both modules are layer 1, so an edge between them is
unrepresentable, not merely discouraged.

**It should not share, either.** The two have opposite failure modes by design. The loader is lenient
and substitutes a fallback so a match still starts (G18); the pipeline is strict and fails a build.
A gate that shares its parser with the thing it gates cannot catch a bug in that parser — a
misread `massKg` would be misread identically on both sides and agree.

**What they must agree on is the codes.** Every check in the builder cites the D08-S5.4 code it
implements, so a finding means the same thing whichever side reported it, and a code that drifts
between them is visible in a grep rather than in a mystery.

**What the pipeline does that the loader cannot.** Cross-file checks: a part's `massKg` against its
fracture manifest's `partMassKg` (A202), the shard masses against that (A504), an assembly's declared
total against the sum of its parts (A310), and the power budget of every vehicle in a class against
`assets/balance/classes.json` (A312, D05-R30). The loader sees one asset at a time by design.

**What neither does yet.** The JSON Schema files of D08-S6.1 do not exist, so A102 is never raised on
either side and the hand-written structural checks stand in for it.

## Rationale / Context
"Two implementations of the same validation" reads as duplication that ought to be refactored away,
and the refactor is architecturally impossible and substantively wrong. This records both halves so
the next session does not spend an afternoon trying.

## Impact
`asset-pipeline` (`AssetIndexBuilder`, `PipelineMain`, `Finding`), `assets/balance/classes.json`.
