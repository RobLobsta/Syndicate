# DEC-033: a vehicle's physics come from a real car; its name does not

**Date:** 2026-08-09
**Category:** decisions
**Related Docs:** docs/05_vehicle_part_system.md#D05-S5.6, docs/08_asset_pipeline.md#D08-S4.4, docs/01_product_game_design.md#D01-S5.7

**Status:** active

## Summary
`VehicleProfile` carries a `displayName` for the in-game vehicle and a separate `referenceVehicle`
naming the real car its figures came from. The Apex GT is derived from a Maserati MC20 and the
Stampede GT3 from a Ford Mustang GT3; neither manufacturer's name appears in an asset id, a display
name or the shipped content.

## Details
Published performance figures — a kerb mass, a 0-100 time, a drag coefficient — are measurements.
Measurements are facts and free to use, and deriving a game's physics from them is exactly what makes
handling feel like something rather than like an arbitrary set of constants.

A manufacturer's name and model designation are trademarks, and a vehicle shipped under one is a
licensing arrangement rather than an engineering decision. Keeping the reference in a field rather
than in the name costs nothing and keeps that decision open: if a licence is ever signed, one string
changes.

The split is visible everywhere it matters. `VEHICLES.md` has a **Reference** column and a
**Sources** section, so nobody has to guess where a number came from; the profile Javadoc separates
**Published** figures from **Derived** and **Estimated** ones; and the asset ids
(`vehicle_apex_gt_01`, `chassis_stampede_gt3_01`) are the game's own.

## Rationale / Context
The obvious shortcut when adding the next car is to call the profile `MASERATI_MC20` and the asset
`vehicle_mc20_01`, because that is what the research says and it is one less name to invent. Asset
ids are load-bearing across content, save data and the network, so renaming them later is a content
migration rather than a rename. This records that the separation is deliberate and cheap to keep.

## Impact
`game-core` `vehicle` (`VehicleProfile`, `VehicleProfiles`), `assets/`, and `VEHICLES.md`. Applies to
every vehicle added afterwards.
