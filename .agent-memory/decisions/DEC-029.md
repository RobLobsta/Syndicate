# DEC-029: the wheel tuning defaults are D06-S4.5's, not Bullet's forklift demo's

**Date:** 2026-08-09
**Category:** decisions
**Related Docs:** docs/06_physics_simulation.md#D06-S4.5, docs/06_physics_simulation.md#D06-S5.5, docs/05_vehicle_part_system.md#D05-S4.5

**Status:** active

## Summary
`VehicleFactory`'s per-wheel constants now carry D06-S4.5's reference chassis values. DEC-022 chose
Bullet demo figures on the reading that no blueprint authored them; D06-S4.5's R12 table authors all
of them.

## Details
D06-S4.5 R12 is titled "`btRaycastVehicle.btVehicleTuning` and per-wheel parameters" and ends
"these are the reference chassis defaults". DEC-022 read it as authoring nothing and reached for
Bullet's forklift demo. Corrected:

| Constant | DEC-022 | D06-S4.5 |
|---|---|---|
| `suspensionStiffness` | 20 | **30** |
| `suspensionCompression` | 4.4 | **2.4** |
| `suspensionDamping` (relaxation) | 2.3 | 2.3 |
| `maxSuspensionTravelCm` | 30 | **25** |
| `maxSuspensionForce` | 12 000 | **15 000** |
| `frictionSlip` | 10.5 | **2.0** |
| `rollInfluence` | 0.1 | **0.15** |
| `suspensionRestLengthM` | 0.30 | 0.30 |

Two of DEC-022's positions survive. **The radius is still derived from the collision mesh**, because
D06-S4.5's own row for `wheelRadiusM` reads "From the wheel part" — the table's 0.42 is now
`WHEEL_RADIUS_FALLBACK_M`, used when a degenerate mesh would otherwise give a zero radius that parks
the vehicle inside the ground. And **the two stats D05-S4.5 does author** — `SUSPENSION_STIFFNESS`
and `FRICTION_SLIP` — are still resolved through `StatBlock.resolve(stat, default)`, which is what
"reference defaults" means: content adjusts them, the table says where from.

The correction is not cosmetic. `frictionSlip` moved by a factor of five, which is the difference
between a vehicle that corners on rails and one that slides.

## Rationale / Context
DEC-022 states as fact that "no blueprint authors either", and a session reading it would not
re-check D06-S4.5. This entry supersedes that claim in place, so the next handling-tuning session
starts from the contract rather than from a demo. It is also a reminder that D06's tuning table is
easy to miss: it sits in the Data Contracts section, several hundred lines above the control loop
that consumes it.

## Impact
`game-core` `vehicle` (`VehicleFactory`). Supersedes DEC-022's constant values; DEC-022 stays as the
record of the radius derivation and of the reasoning about roll influence.
