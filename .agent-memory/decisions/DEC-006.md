# DEC-006: Blueprint invariants are enforced by Gradle check tasks, not by convention

**Date:** 2026-08-08
**Category:** decisions
**Related Docs:** docs/02_technical_architecture.md#D02-S5.6, docs/12_testing_validation_ci.md#D12-S5.4

**Status:** active

## Summary
Every mechanically checkable rule in D02 and D00 is implemented as a Gradle task in `build-logic/` and wired into `check`, rather than left as a documented convention. The module catalogue of D02-S4.5 is duplicated as data in `ModuleRules.kt` so the checks have something to compare against.

## Details

Implemented in `build-logic/src/main/kotlin/dev/syndicate/build/`:

| Task | Enforces | Verifies |
|---|---|---|
| `:checkLayering` | D02-S5.6 layer ordering + MUST NOT column | AC-D02-3 |
| `:game-core:checkHeadlessSafety` | D02-R9, source scan and runtime classpath scan | AC-D02-4 |
| `:validateDocs` | D00-S5.3 citations + D00-S5.4 section structure | AC-D00-13, AC-D12-6 |
| `:checkVersionCatalog` | D02-R1, no inline version strings | AC-D02-5 |
| `:<module>:checkPackageRoots` | D02-R13 | AC-D02-11 |
| `:memory-system:lintMemory` | D13-S5.8 L1-L15 | AC-D13-2 |

Two design points worth keeping:

- **`checkHeadlessSafety` scans both sources and the runtime classpath.** A source scan alone misses D02-E5, where a new dependency drags a backend in transitively; a classpath scan alone misses a hand-written import of a banned package. Both failures are real and neither implies the other.
- **`ModuleRules.kt` duplicates the D02-S4.5 table.** Duplication is accepted deliberately: the alternative is parsing Markdown at build time, which makes the build fail for formatting reasons. The rule is that the table and this file change in the same commit, which is stated in the failure message the task prints.

## Rationale / Context
G17 and the layering rules are the invariants most likely to be broken by an ordinary, well-intentioned change — adding one dependency to `game-core` for convenience silently breaks the dedicated server, and the symptom appears much later as a crash on a host with no GL driver. A rule that only exists in a document is discovered after it is violated.

## Impact
`build-logic/`, every module's `check` task, and CI stage 0 (D12-S5.4). Any future change to the D02-S4.5 module table must update `ModuleRules.kt`.
